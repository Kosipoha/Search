# HH Vacancy Notifier

Небольшая программа ищет вакансии на hh.ru по заданным критериям и отправляет новые ссылки в Telegram.

## Запуск

Нужен Python 3.9 или новее. Внешние Python-пакеты не требуются.

1. Создайте Telegram-бота через `@BotFather`, получите токен и узнайте ID чата, куда бот должен писать. Для личного чата сначала откройте бота и отправьте ему `/start`.
2. Скопируйте `config.example.json` в `config.json` и заполните `telegram_bot_token`, `telegram_chat_id` и `contact_email` настоящим контактным email. hh.ru требует email в заголовке `User-Agent`.
3. Настройте поисковый запрос, регион и фильтры в `config.json`.
4. Запустите из папки проекта:

   ```sh
   python3 main.py
   ```

Программа проверяет вакансии с интервалом `interval_seconds`. Для одного цикла используйте `python3 main.py --once`, для проверки найденных вакансий без отправки и сохранения состояния — `python3 main.py --dry-run`.

Уже отправленные ID вакансий сохраняются в `sent_vacancies.json`. Файл можно удалить, если нужно начать отслеживание заново. Токен бота храните только в локальном `config.json`; не публикуйте его.

## Фильтры

`employment` и `experience` принимают значения API hh.ru. Если указано несколько значений, программа выполнит отдельный запрос для каждой пары фильтров.

- Занятость: `FULL`, `PART`, `PROJECT`, `VOLUNTEER`, `PROBATION`.
- Опыт: `noExperience`, `between1And3`, `between3And6`, `moreThan6`.
- `area` — ID региона hh.ru; `null` означает поиск без ограничения по региону.
- `period_days` — глубина поиска, от 1 до 30 дней.
